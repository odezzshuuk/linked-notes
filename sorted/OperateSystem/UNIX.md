# Begin With Operating System Background

## Linux Unix GNU


### What is Unix

- Operating system developed in 1969
- Features:
  - Multi-user
  - Multi-process
  - All data stored as plain text
  - Simpler than Multics operation

#### Unix Philosophy

- Build **modular** programs
- Write **readable** programs
- Use composition
- Separate mechanisms from policy
- Write simple programs
- Write small programs
- Write transparent programs
- Write robust programs
- Make data compllicated when required,not the program
- Builid on potential users exoected knowledge
- Avoid unneccessary output
- Write programs which fail in a way that is easy to diagnose
- Value developer time over machine time
- Write abstract programs that generate code instead of writing code by hand
- Prototype software before polishing it
- Write flexible and open programs
- Make the program and protocols **entensible**

### What is Linux

- Open-source **operating system kernel** based on Unix principles
- The commonly referred Linux distribution usually means a GNU/Linux distribution
- The Linux operating system includes the Linux kernel and other GNU components and software from free software projects


### What is GNU

- GNU is not Unix. GNU is an operating system project, including editors, compilers, debuggers, and the C library.
- The initiators of GNU hoped to develop a complete open-source operating system to replace Unix.
- The development of GNU is still incomplete; the biggest problem is that a fully functional kernel has not yet been successfully developed. The GNU kernel is called Hurd.
- In practice, most use the Linux kernel. GNU developers have already ported GNU applications and tools to Linux.


#### GNU Components

- GCC: GNU Compiler Collection
- glibc: GNU C Library
- coreutils: GNU Core Utilities
- [GDB](unix-gdb.md): GNU Debugger
- binutils: GNU Binary Utilities
