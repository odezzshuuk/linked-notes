## Content Categories

- Each HTML element must follow rules about what type of content it can have
- Several common content models:
  - Main content categories
    - Metadata type
    - Flow content
    - Sectioning content
    - Heading content
    - Phrasing content
    - Embedded content
    - Interactive content
    - Palpable content
    - Form-associated content
    - Secondary content
    - Transparent content
  - Form related content categories
  - Specific content categories
- Each HTML element belongs to zero, one, or multiple content models, and all element content setting rules must follow the HTML consistency document.
