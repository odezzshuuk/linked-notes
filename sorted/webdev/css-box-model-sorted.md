# CSS Box Sorting

## block box

- block
- will break onto a new line
- ~~default width is 100% of parent~~
- width and height property will be respected
- padding, margin, border will let other element away from the box
- default block-level elements: div, p, h1, ul, ol

## inline box

- **not** break onto a new line
- `width` and `height` will not be respected
- horizontal padding, margins, borders, will cause other elements to be pushed away
- default inline-level elements: span, a, strong, em, img
