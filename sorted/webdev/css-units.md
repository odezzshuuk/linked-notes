# CSS - Unit

## Abosulte Unit

px

- Pixels

## Relative Unit

em

- 1em equals the font-size of current element

rem

- 1rem equals the font-size of the root element (usually `<html>`)

percentage

- percent of parent element or [containing block]() CSS property

vw, vh

> view port

- 1% of viewport width
- 1% of viewport height
