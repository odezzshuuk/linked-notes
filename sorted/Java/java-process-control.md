## switch...case...

- When the variable's value equals the value in a case statement, statements after the case statement start executing until a break statement appears to exit the switch statement
- Advantage: High efficiency
- Disadvantage: Limitations
  - Can only judge equality
  - Condition can only be integer types (byte, short, char, int) or string

## Jump Out of Loop

- break: Exit loop
- continue: Skip current iteration of current loop
