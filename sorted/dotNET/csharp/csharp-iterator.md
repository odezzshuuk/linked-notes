# CSharp - Iterator

## What Is Iterator

- Each iteration of the `foreach` loop calls the [iterator](csharp-iterator.md) method.
- `foreach` or [LINQ](csharp-linq.md) query can be used to consume the sequence returned by an iterator method. 

## 2 Ways Implementation

1. [`IEnumerable`](csharp-ienumerable.md) interface
2. yield return within methods or properties
