# Unity Entities - Baking

## What's this

- Converting data from [authoring](unity-entities.md#authoring) data into ECS data 
- Process that converts GameObjects data into [entities](#entity)

## Features

- Only run in the editor

## Baker

What's for

- unity use baker to read data from the input [authoring](unity-entities.md#authoring) scene
- write to ecs component

Create Baker

- use `Baker<TAuthoring>` to create a baker
