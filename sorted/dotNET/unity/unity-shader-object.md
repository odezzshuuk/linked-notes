# Unity - Shader Object

## What's This

- In unity, Object that assign to a material

## Shader Object Can be Create By

- write .shader file use [ShaderLab](unity-shaderlab.md)
- `.shadergraph` file

## Error Shader 

- When there is an error in [shader object](), the object will be pink
- Actually, the pink is the default error shader object

## Standard Shader

When use standard shader, there are 2 choice

- Standard
- Standard(Specular Setup)

With Standard 

- The material inspector has a metallic value property to states whether the material is metallic or not

With Standard(Specular Setup)

- The material inspector has a specular color property to control the color and strength of specular reflection in the material
