## How to

## What Can Be Import From Blender

- All nodes with position, rotation and scale; pivot points and names
- Meshes with vertices, polygonsl, triangles, UVs, and normals
- Bones
- Skinned Meshes
- Animations 

## Optimize Performation

- Minimize the polygon count
- Use as few Materials as possible
- Use single skinned Mesh Renderer
- Use as few bones as possible
- Keep forward and inverse kinematics separate
