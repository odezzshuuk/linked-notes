# Unity - GameObject

## What It Is

- Some objects are not visible in the scene, such as cameras and lights
- Which can be create unity editor press `+` in the hierarchy window
- Empty GameObject, only have a `Transform` component, execute translation, rotation, and scaling.
- They are GameObject
  - [MonoBehavior](unity-monobehavior.md)
  - [ScriptableObject](unity-scriptableobject.md)
