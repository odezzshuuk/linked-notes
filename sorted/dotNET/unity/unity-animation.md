# Unity - Animation

## Features

Provide numerous features for handling **humanoid characters**

- Which giving the ability to retarget animation to character model
- This Feature Provides by [Avatar](#avatar) System

## 3 Key Parts of Unity Animation System

- Animation Clips
- Animator Controller
- Avatar

Relationship between these 3 parts

- Animation Clips controlled by Animator Controller

## How To Animate A Character

1. Animation Clips, Animator Controller, Avatar attach on a GameObject via [Animator Component](unity-script.md)
2. Assigning [Animator Controller]() and [Avatar]()
