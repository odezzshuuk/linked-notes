# USS

## BEM name convention

BEM: Block Element Modfier

- Block name: entity or control, for example, `button`, `label`, `list-view`
- Element name: part of block, no standalone meaning, for example, `button__text`, `list-view__icon`
- Modifier name: change appearance or behavior, for example, `button--disabled`, `list-view--selected`

```css
.BlockName__ElementName--ModifierName {
    /* style */
}
```
