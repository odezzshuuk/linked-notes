# Glossary

## ECMAScript

- The standardization organization for JavaScript is ECMA
- This standardized version of JavaScript is called ECMAScript

## CommonJS

- Proposed specifications to enable JavaScript to develop large-scale applications
  - Server-side JavaScript applications
  - Command-line tools
  - Desktop GUI applications
  - Hybrid applications
- The CommonJS specification covers modules, binary, Buffer, character encoding, I/O streams, process environment, file system, sockets, unit testing, web server gateway interface, package management, etc.
