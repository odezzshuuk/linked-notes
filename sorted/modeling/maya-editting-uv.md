#  Maya - Editting UV

## How To Create UV

Step 1. UV Editor

Step 2. Create UV 

- In `UV Editor main menu -> Create -> automatic/camera-based/normals-based`

Step 3. Cut UV 

- Select edges, cut uv in UV Toolkit/quick menu
- Or use auto seams. `UV Editor main menu -> Cut/Sew -> Auto Seams`

Step 4. Select UV 

- right click set select mode to UV, this will select the UV vertices
- right click set select mode to UV Shell, this will select the a piece of UV

Step 5. Layout

- `UV Toolkit -> Layout` to auto layout UV in 0-1 space

## How To Edit UV

1. unfold: to avoid overlapping UVs

- Fold uv, Which UV block shape is a rectangle

![fold uv](/image/fold-uv.png)

- unfold uv, Which UV block shape is a square

![unfold uv](/image/unfold-uv.png)

2. straighten: to align UVs

3. layout: to layout UVs at 0-1 space

## Tips

- if created uv shell is scattered, try `cleanup` the mesh
