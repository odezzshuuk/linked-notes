## Delete vertices separate two edge in same line

1. Select all the vertices, Press Delete
2. Shift + Right Click, Select `Merge Vertices -> Target Weld`, the drag the vertices to the target

## Create Edges Manually

1. Shift + Right Click, Select `Multi-Cut Tool`, choose vertices or edges(without holding ctrl)

## Create Edge Loop

1. Shift + Right Click, Select `Multi-Cut Tool`, Press Ctrl
2. Shift + Right Click, Select `Insert Edge Loop Tool`, Click on the edge
3. Select Edges, Shift + Right Click, Select `Connect Components`

> 1, 2 are most common ways to create edge loop, 
> but in some unknown cases, 1, 2 is inavailable, choose 3 alternative

## Split Faces By Pole

> what is [pole](topology-glossary.md#pole)

1. Shift + Right Click, Select `Poke Face`

## Replace Vertices With Face

1. Select Vertices, Shift + Right Click, Select `Charmfer`
