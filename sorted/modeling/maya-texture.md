## Bake Normal Map

> What is [normal map](modeling-glossary.md#normal-map)

1. Open Transfer Maps
2. Set Target Mesh: the mesh you want to bake normal map to, usually a low-poly mesh
3. Set Source Mesh: the mesh you want to bake normal map from, usually a high-poly mesh

Caveat 

1. two meshes should have high coincidence at postion
2. to preview the texture, press 6 to enable texture display mode
