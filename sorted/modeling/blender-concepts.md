# Blender - Concepts

## Vertex Groups

- Have large number of asociated vertices
- Mainly used to tag the vertices belonging to parts of the mesh
- For example leg, arms, head of a character belong to different vertex groups
- Most commonly used for armatures

## Active Object

What It Is

- Active object is the last selected object in multiple selection
- Object selected as Active default has outline **yellow(#FFA802)** color, the other are orange(#ED5700)

Features

- Many operations use Active Object as reference
