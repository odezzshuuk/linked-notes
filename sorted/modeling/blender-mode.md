## Weight Paint

- Mainly used in Rigging, where [vertex groups](blender-glossary.md#vertex-groups) are used to define the influence of bones on the mesh
- Value of Weight is used to describe the influence of the bone on the vertices
- Weight Value is between 0 and 1
- Color visualizes weights associated to each vertex
  - red means fully weighted, value close to 1
  - blue means no weight, value close to 0
