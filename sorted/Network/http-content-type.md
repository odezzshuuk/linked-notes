# Content-type

- The content type of a web page, which determines how the browser will read this file and with what encoding.
- Common media types:
  - text/html: HTML format
  - text/plain: Plain text
  - text/xml:
  - image/gif:
  - image/jpeg:
  - image/png:
- Media format types starting with application:
  - application/xhtml+xml: XHTML format
  - application/xml
  - application/atom+xml
  - application/JSON
  - application/pdf
  - application/msword
  - application/octet-stream
  - application/x-www-form-urlencoded: Encodes [form data](http-request-message.md) into key/value format and sends it to the server.
