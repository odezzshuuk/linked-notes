# Chromium PWA

## What is a PWA?

## Where PWA Desktop Command Options

- Based on PWA installed environment, it has different command options.
- For regular environment installed PWA, command options generally look like this:

```bash
chromium --profile-directory=Default --app-id=xxxx
```

- For Browser run with options, for example `chromium --user-data-dir=path/to/dir --profile-directory=Profile 1`, the PWA command options generally look like this:

```bash
chromium --user-data-dir=path/to/dir --profile-directory=Profile 1 --app-id=xxxx
```
