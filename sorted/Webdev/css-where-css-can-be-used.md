# Where CSS can be used

## External Stylesheet

Syntax:

```html
<link rel="stylesheet" type="text/css" href="filepath">
```

## Internal Stylesheet

Syntax:

```html
<style type="text/css">
  div {

  }
</style>
```

## Inline Stylesheet

Defined in the style attribute of the tag

```html
<body>
<div style="color:red">分区样式</div>
</body>
```
