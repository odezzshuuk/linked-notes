# HTML - Element input

## value

- value: input

Property `value`

- value for init value, like `<input value="init">`

## type attribute

```html
<input type="text" name="username" value="init">
```

- work mode of `<input>` tag depends on `type` attribute
- default value is `text`
- avaible values:
  - button
  - checkbox
  - color
  - date
  - datetime-local
  - email
  - file
  - hidden
  - image
  - month
  - number
  - password
  - radio
  - range
  - reset
  - search
  - submit
  - tel
  - text
  - time
  - url
  - week
