# PhotoShop

## Glossary

Group Layer

- organize layer together

Linked Layer

- Transformation will be applied to all linked layers

## Zoom In/Out Shortcut

- Press `z` then drag mouse to zoom in/out

## Pan Move Shortcut

- Hold `Space` then drag mouse to move

## Adjustment

- Remove any flaws such as dust spots, blemishes, and scratches from the image **BEFORE** making color and tonal adjustments.

## Discard Image Overflow Canvas

- select all
- Image -> Crop in main menu

## Select By Color

- Main menu: Select -> Color Range, use color picker to select color

## Create Mask From Layer 

1. Use marquee to create area  
2. fill with white/black color
3. [select by color](#select-by-color) to select the area
4. create mask from selection

## Thick Line

- Main menu: Filter -> Other -> Minimum

## Duplicate Selection

1. Right Click -> Layer via copy
2. Apply copied layer
