## Relationships

- <font color="red">A pointer or reference to a base class can be bound to a derived class.</font>
- <font color="red">A pointer or reference to a base class cannot be converted to a derived class.</font>

## Base Class

- `virtual` members
- `static` members: only a **single** instance exists in the entire inheritance hierarchy, following access control.
- A class must be defined before it can be used as a base class.
- Adding `final` after a class name indicates that the class cannot be inherited.

## Derived Class

- `class A : public B {}`, A is a derived class of B, A inherits from base class B.
- Contains members of the base class and custom members of the derived class.
- Members inherited from the base class must be initialized using the **base class's** constructor.

## Static Type and Dynamic Type

- The dynamic type and static type of a variable or expression **coexist**.
- Static type: the type of a variable at <font color="red">declaration</font> or the <font color="red">type generated by an expression</font>.
  - Determined at compile time.
  - Which members are accessible is determined by the **static type**.
- Dynamic type: the type of the object in memory represented by a variable or expression, the actual type.
  - The range of change of the dynamic type does not exceed the entire derivation hierarchy.
  - Determined only when a function is called at runtime.
  - The conversion between inherited types is a conversion of the **dynamic type**.
- If an expression is neither a **reference** nor a **pointer**, its dynamic type and static type are the same.

## Conversions Between Types with Inheritance Relationships

- <font color="red">The conversion from a derived class to a base class is only valid for pointers or references.</font>
- A derived class may have members that a base class does not, so a base class cannot be converted to a derived class.
- The conversion from a derived class to a base class may also become infeasible due to [access restrictions](accessibility-restrictions-on-derived-to-base-conversion.md).
- There is no implicit conversion from a base class to a derived class.
- There is no conversion between objects; during assignment and copying, what is actually converted is the implicit conversion of the parameters.
